# Work Log — Certifications Feature

**Date:** 26 October 2026
**Project:** ASG Website (`asg-web`)
**Area:** Homepage "Certifications and Compliance" section + new `/certificates` page

---

## Summary

Today we completed the end-to-end **certificate viewing feature**: certification
logos are now clickable and open a full **PDF preview** (page-by-page), and we
added a dedicated **"View All Certificates"** page that lists every certificate
in a grid using the same preview.

---

## What was built / changed

### 1. Certificate PDF preview lightbox (new)
- **File:** `components/homepage/CertLightbox.tsx`
- A full-screen overlay (same look & feel as the Media Galleries lightbox —
  dark blurred backdrop, close/download buttons, open & exit animations,
  Esc-to-close, scroll lock).
- Renders the certificate **PDF** onto a `<canvas>` using **`pdfjs-dist`**
  (Mozilla PDF.js).
- **Page navigation rules:**
  - **1-page** certificate → **no** left/right arrows (nothing to navigate).
  - **More than 1 page** → left/right arrows + a **"Page X / N"** counter appear.
    Arrows disable at the first/last page; arrow keys also work.
- **Preview size fits the certificate** (not a fixed rectangle) — portrait
  certificates render tall, landscape render wide, and the **full page is always
  visible**.
- **Download button** opens/saves the original PDF; its label also shows on
  mobile (only the icon size differs).
- Navigation arrows are **white** (matching the Media page) with a soft dark
  drop-shadow so they stay visible over the white certificate.

### 2. Homepage section made interactive
- **File:** `components/homepage/CertificationsCompliance.tsx`
- Clicking any certificate tile in the auto-scrolling strip opens the PDF
  preview for **that exact certificate**.
- Tiles **without** a backing PDF are **not clickable** (no preview option).
- Added **drag-vs-click detection** so scrubbing/dragging the slider never
  accidentally opens a preview.

### 3. New "View All Certificates" page
- **Route:** `/certificates`
- **Files:**
  - `app/certificates/page.tsx` — page (header + grid).
  - `components/certificates/CertificateGallery.tsx` — responsive card grid
    (1 / 2 / 3 / 4 columns by breakpoint); clicking a card opens the same
    `CertLightbox` PDF preview.
  - `components/certificates/certData.ts` — **single shared source** of
    certificate data (`label`, logo `src`, optional `pdf`) used by both the
    homepage strip and the new page.
- A **"View All Certificates"** gradient pill button was added to the **top-right**
  of the homepage section, linking to `/certificates`.
  - On mobile the header stacks (button sits below the heading) so it never
    overflows/clips.
  - The button label has an `aria-label` for accessibility.
  - (Final tweak today: removed the arrow icon from the button label — text only.)

### 4. PDF.js assets & dependency
- Installed **`pdfjs-dist`** (`package.json`).
- Copied version-matched assets into `public/` so they work reliably under
  **Turbopack** (Next 16 dev):
  - `public/pdfjs/pdf.worker.min.mjs`
  - `public/pdfjs/wasm/*` (OpenJPEG/JBIG2/QCMS decoders — prevents some
    certificate images from being silently dropped).

## How to run / verify

```bash
npm install       # pulls in pdfjs-dist
npm run dev       # starts the dev server
```

- Homepage → "Certifications and Compliance" section → click a certificate to
  preview; multi-page ones show left/right arrows + "Page X / N".
- Click **"View All Certificates"** (top-right) → `/certificates` → click any
  card to preview.
